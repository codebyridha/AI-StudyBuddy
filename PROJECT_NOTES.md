# StudyBuddy Project Notes

This implementation follows the provided AI StudyBuddy project document.

Technology track: AI-Augmented Backend Development

Core stack specified in the document:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Multer
- Google Gemini API
- Postman

Core features specified:
- Secure authentication
- Study material management
- AI summary generation
- AI flashcard generation
- AI quiz generation
- AI personalized study plan
- Student/Admin RBAC

The implementation is organized using MVC-style separation between models, controllers and API routes, with middleware and utility modules separated from business logic.
